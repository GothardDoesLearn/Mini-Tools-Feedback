# Feedback-Tools

Eine öffentliche Website mit einer Sammlung kurzer Feedbackmethoden, mit denen Lehrkräfte aller Schulen im Unterricht Rückmeldungen von Schülerinnen und Schülern einholen.

## Sammlung

**Feedback-Tools**:
Der Name der Sammlung und der Website als Ganzes (entschieden 2026-11-25; früherer Arbeitsname „Mini-Tools“). Kein Begriff für eine einzelne Methode und nicht zu verwechseln mit **Tool** (digitales Tool).
_Vermeiden_: Feedback-Tool oder Mini-Tool (im Singular für eine Methode)

**Methode**:
Eine einzelne Feedbackmethode der Sammlung, zum Beispiel die Daumenprobe.
_Vermeiden_: Mini-Tool, Tool, Übung

**Kategorie**:
Eine der sieben Gruppen (A–G), in die jede Methode genau einmal eingeordnet ist.
_Vermeiden_: Rubrik, Bereich

**Tool**:
Ein externer digitaler Dienst, auf den die Website verweist, zum Beispiel Oncoo oder Mentimeter. Tools sind keine Kategorie.
_Vermeiden_: App, digitale Methode, Kategorie H

**Druckvorlage**:
Ein druckbares A4-Material, das zu einer oder mehreren Methoden gehört.
_Vermeiden_: Vorlage, Material, Arbeitsblatt

**Material**:
Was eine Lehrkraft für eine Methode bereithalten muss, als kurzer Text beschrieben. Kann eine Druckvorlage einschließen, ist aber nicht dasselbe.

**Werbeplatz**:
Eine feste Stelle im Layout, an der später Werbung erscheinen darf. Nie auf einer Druckvorlage oder in der Druckansicht.
_Vermeiden_: Banner, Anzeigenfläche

**Hinweis**:
Eine Mitteilung einer Lehrkraft an den Betreiber zu einer Methode, einer Druckvorlage oder der Website: ein Fehler, eine Ergänzung, eine Rückfrage oder der Vorschlag einer neuen Methode.
_Vermeiden_: Feedback, Rückmeldung, Kommentar (diese meinen das Feedback der SuS)

**Statushinweis**:
Die sichtbare Kennzeichnung einer Methode, Druckvorlage oder Seite, die nicht fertig ist (Status Annahme, Platzhalter oder Entwurf). Kein Hinweis im obigen Sinn.
_Vermeiden_: Hinweisbox

## Status

**fertig**:
Ablauf und Inhalt einer Methode oder Druckvorlage sind geprüft.

**Annahme**:
Der Ablauf ist eine begründete Vermutung und wird noch beim Kollegium geprüft. Wird auf der Website sichtbar gekennzeichnet.

**Platzhalter**:
Der Inhalt fehlt noch und folgt nach Rücksprache. Eine Druckvorlage im Status Platzhalter zählt nicht als vorhanden.

**Entwurf**:
Ein Text, den ein Agent geschrieben oder gewählt hat und den der Betreiber noch nicht freigegeben hat. Bei Seiten (z. B. Über) wird er auf der Website sichtbar gekennzeichnet.
_Vermeiden_: Vorschlag, vorläufig

## Personen

**Lehrkraft**:
Jede Person, die die Website nutzt, um eine Methode einzusetzen, an jeder Schule und auch in Fortbildungen.
_Vermeiden_: Lehrer, Nutzer, Referent:in, Fortbildner:in

**SuS**:
Schülerinnen und Schüler, die mit einer Methode Feedback geben oder bekommen. Sie nutzen die Website nicht selbst.
_Vermeiden_: Schüler, Lernende
