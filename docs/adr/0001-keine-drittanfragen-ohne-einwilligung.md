# Keine Anfragen an Drittserver ohne Einwilligung; Werbung vorbereitet, aber ausgeschaltet

Mini-Tools ist eine öffentliche Website, die der Betreiber privat hostet und für die er datenschutzrechtlich selbst verantwortlich ist. Ein späteres Geld verdienen mit Werbung soll möglich bleiben. Deshalb lädt keine Seite beim bloßen Öffnen etwas von Drittservern: Schriften liegen lokal, es gibt keine Tracker und keine Cookies. YouTube-Videos werden nur per Zwei-Klick eingebettet (eigenes Vorschaubild, das Video lädt erst nach aktivem Klick), dazu gibt es immer einen direkten Link. Für die Werbung sind feste Werbeplätze als Komponenten im Layout angelegt, damit das Design später nicht verrutscht. Sie sind über die Konfiguration ausgeschaltet. Druckvorlagen und die Druckansicht zeigen nie Werbung.

## Consequences

- Werbung einzuschalten verlangt zuerst ein Einwilligungs-Tool (Consent-Banner). Die Zwei-Klick-Einbettung von YouTube soll dann an dasselbe Tool angebunden werden.
- Die Regeln „keine Drittanfragen, keine Cookies“ und das Lighthouse-Ziel gelten verbindlich nur, solange die Werbung ausgeschaltet ist.
