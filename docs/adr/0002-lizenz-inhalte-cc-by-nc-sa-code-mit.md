# Lizenz: Inhalte CC BY-NC-SA 4.0, Code MIT

Das Repo ist öffentlich, damit Lehrkräfte die Inhalte frei nutzen, drucken, teilen und anpassen können. Der Betreiber will sich aber vorbehalten, die Website später mit Werbung zu finanzieren. Deshalb stehen die Inhalte (`content/`, Druckvorlagen) unter CC BY-NC-SA 4.0. Dritte dürfen sie nicht kommerziell nutzen; der Betreiber als Rechteinhaber ist an die NC-Klausel nicht gebunden. Der Code steht unter MIT, weil er keinen eigenständigen Wert hat, der geschützt werden müsste.

## Considered Options

- CC BY-SA 4.0: verworfen, weil dann jemand die Inhalte komplett kopieren und selbst mit Werbung anbieten dürfte.
- Alle Rechte vorbehalten: verworfen, weil Schulen sonst keine angepassten Kopien anfertigen dürften.

## Consequences

- Eine einmal erteilte CC-Lizenz lässt sich für bereits veröffentlichte Fassungen nicht zurücknehmen.
- Voraussetzung ist, dass die Texte eigene Formulierungen sind und nicht aus fremden Unterlagen übernommen wurden.
